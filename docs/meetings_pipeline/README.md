## Архитектурные принципы
1. **First Make It Work, Then Make It Right**: Используется существующая модель Gemini для анализа, без перегруза системы дополнительными локальными сетками.
2. **Нулевая ручная нарезка аудио**: Движок C++ Whisper.cpp сам прожевывает часовые файлы через внутреннее скользящее окно, исключая разрезание слов.
3. **Turn-based RAG**: Векторизация ведется строго по смысловым репликам спикеров с контекстным заголовком, что дает точные ответы на вопросы вида «Что говорил Максим про сроки печати?».
