## 🎨 Дизайн-система: Linear & Raycast Obsidian Pro

### 1. Цветовая палитра и поверхности
* **Фон страницы**: Глубокий матовый графит `#08090c` (без глянца и кричащих пятен).
* **Поверхности карточек (Surfaces)**:
  * Базовая карточка: `#0f1015` с тончайшей границей `border: 1px solid rgba(255, 255, 255, 0.07)`.
  * Интерактивная карточка при наведении: плавное осветление до `#14161f`, появление слабого внутреннего радиального градиента `radial-gradient(circle at 50% 0%, rgba(255, 255, 255, 0.04), transparent 60%)`.
* **Акценты (Subtle Indication)**:
  * 95% интерфейса строго монохромно (градации белого, платинового `#e2e8f0` и нейтрального цинкового `#71717a`).
  * Цвет используется точечно для индикации статусов:
    * Холодный индиго `#6366f1` — активный фокус и основные действия.
    * Изумрудный `#10b981` — активный статус системы и успешные задачи в Битрикс24.
    * Янтарный `#f59e0b` — предупреждения и ограниченные права (RBAC).
* **Хоткеи и чипы (Keyboard Badges)**:
  * Оформление в стиле Raycast: `<kbd class="kbd-chip">Enter</kbd>`, `<kbd class="kbd-chip">Esc</kbd>`.
  * Стиль: `background: #181920; border: 1px solid #27272a; border-radius: 4px; padding: 1px 6px; font-size: 11px; font-family: monospace; color: #a1a1aa;`.

### 2. Иконки: Векторный минимализм Lucide
* Подключить официальный CDN **Lucide Icons**:
  `<script src="https://unpkg.com/lucide@latest"></script>`
* Заменить все эмодзи на строгие векторные иконки со штрихом `stroke-width="1.5"`:
  * Бренд: `<i data-lucide="printer"></i>`
  * Статус модели: пульсирующая микро-точка (status dot) с зеленой подсветкой.
  * Чат: `<i data-lucide="terminal"></i>` (ассистент) и `<i data-lucide="user"></i>` (пользователь).
  * Ввод: иконки `<i data-lucide="paperclip"></i>` и `<i data-lucide="mic"></i>` в темных квадратных кнопках с легким скруглением (`border-radius: 8px`).
  * Быстрые действия: лаконичные кнопки-таблетки со значками `<i data-lucide="box"></i>`, `<i data-lucide="bar-chart-2"></i>`, `<i data-lucide="check-circle-2"></i>`, `<i data-lucide="calendar"></i>`.
  * Модуль протоколов (MoM): `<i data-lucide="file-check"></i>`, `<i data-lucide="clock"></i>`, `<i data-lucide="arrow-down-to-line"></i>`.

## ⚙️ Функциональные инварианты (ОБЯЗАТЕЛЬНО СОХРАНИТЬ)
Новый интерфейс обязан на 100% поддерживать весь имеющийся функционал:

1. **Диалоговый движок (`/api/agent/chat`)**:
   * Передача `{ telegramId, chatId, message }`.
   * Анимированный лоадер печати (три минималистичные точки).
   * Поддержка полного markdown: строгие монохромные таблицы с границами `#27272a`, код в темных блоках `<code>`, заголовки и списки.
   * Бейджи вызванных MCP-инструментов и веток n8n в виде компактных моноширинных тегов.

2. **RBAC Переключатель пользователей (`/api/agent/users`)**:
   * Загрузка списка пользователей (директор, производство, продажи, бухгалтерия, гость).
   * Сохранение выбора в `localStorage` по ключу `fotoprint_telegram_id`.
   * Отображение компактного селектора в шапке с бейджем роли и всплывающим системным сообщением при смене.

3. **Голосовой ввод и звуковая визуализация (ChatGPT / Linear Audio Bar)**:
   * Запись аудио через Web Audio API с очисткой ресурсов (`AudioContext`, `MediaStream`, `MediaRecorder`).
   * Строгая компактная панель записи (`#voice-bar`): таймер с моноширинными цифрами, кнопка отмены `✕` (`Esc`), кнопка отправки `✓` (`Enter`).
   * Высокоточный рендеринг волны звука на Canvas `#voice-waveform`: аккуратные тонкие монохромные столбцы с легким свечением.
   * Отправка на `/api/audio/transcribe?language=ru` с информированием о статусе в виде компактного статус-бара.

4. **Анализ аудио встреч и генерация протокола MoM (`/api/meetings/process-audio`)**:
   * Загрузка аудиофайла совещания через скрытый `input` и кнопку-скрепку.
   * Рендеринг структурированной карточки протокола в стиле Linear Issue:
     * Заголовок совещания, плашка провайдера (Gemini / Whisper) и длительности.
     * Секции: Сводка встречи, Принятые решения, Обсуждение, Риски, Требует уточнения.
     * Задачи (Action Items) с ответственными, сроками и кнопкой интеграции «В Битрикс24».
     * Кнопка скачивания `.DOCX` (декодирование base64 или роут `/api/meetings/{id}/export-docx`).

5. **Создание задач в Битрикс24 (`/api/telegram/webhook`)**:
   * Отправка callback-запроса `create_bitrix_task:<id>` с визуальной фиксацией успешного создания задачи.

6. **Быстрые запросы и навигация**:
   * Верхние ссылки на n8n (`:5678`), Langfuse (`:3000`) и Метрики системы.
   * Быстрые промпты в виде элегантных чипов с микро-иконками.
